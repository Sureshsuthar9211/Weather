# 🌤️ Weather Web App

A responsive weather web application that allows users to search for a city and view its current weather information using a weather API.

## 🚀 Features

- 🔍 Search weather by city name
- 🌡️ Displays current temperature
- ☁️ Shows weather condition
- 💧 Displays humidity
- 💨 Shows wind speed
- 📱 Fully responsive design
- ⚠️ Handles invalid city names and API errors

## 🛠️ Technologies Used

- **HTML5** – Structure
- **Bootstrap** – Styling and responsive design
- **JavaScript** – Functionality and API integration
- **Weather API** – Fetching real-time weather data

## 🌐 API Used

This project uses the **OpenWeather API** to fetch real-time weather data.

🔗 [OpenWeather API](https://openweathermap.org/api)

## ⚙️ How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/weather-web-app.git
   ```

2. Open the project folder.

3. Add your API key in the JavaScript file if required.

4. Open `index.html` in your browser.
